Spot On! JukeBar for Android

Spot On! JukeBar turns an Android phone or tablet into the whole jukebox: it plays a Spotify playlist or your own uploaded MP3s, runs the QR-code request system, and serves the admin/ bartender screens — all from one device. This page is the full manual: first-run setup, network options, troubleshooting, and Spotify/local-file privacy notes. For the general pitch and pricing model, see the overview page.

Good fit for

Bars that run their music through Spotify, or that want to mix a Spotify streaming playlist with their own uploaded MP3s on one device — including offline nights on local files only, with no internet or Spotify subscription needed for that part of the catalog.

Setup guide

The setup wizard runs on first launch and again any time you use End Session from the admin screen — every choice below is changeable later, nothing is locked in.

1. Pick a kiosk mode

  • Local Only — requests are entered directly on this device. No customer phones, no QR code, no network needed.
  • Remote Only — customers connect from their own phones after scanning the kiosk's QR code.
  • Local + Remote — both at once.

2. Pick how customers connect (skipped in Local Only mode)

  • Bar WiFi — customers join the same router you're on.
  • Android Hotspot — your Android device becomes the router; customers connect to your hotspot directly, no external router needed.
  • Internet / Relay — customers connect over the internet from anywhere via a QR link that works off any network. The device still plays the music locally; only requests/approvals/now-playing pass through the relay.

3. Music source

  • Local MP3 folder (optional)

    Pick a folder of local audio files on the device to use as (part of) the catalog — skip this step entirely if you're Spotify-only.

  • Spotify device

    Sign in via Spotify (browser-based login) and select the Spotify playback device — skip to go local-files-only.

  • Spotify playlist

    Choose the Spotify playlist to use as the streaming source. Local files and a Spotify playlist can be used together — JukeBar intermixes them; the Spotify portion needs internet + an active Spotify subscription, the local-file portion works fully offline.

4. Bar details & admin

  • Name your jukebox & discovery

    Give this instance a name. Optionally toggle "List on JukeBar map" to publish the bar name, an address you type in for the map marker, and playlist band names to the JukeBar discovery map. Off by default, changeable any time via End Session.

  • Set the admin PIN

    4–6 digits, entered twice to confirm.

  • Choose payment methods

    Two independent toggles — Stripe — Pay Online and Pay to bartender — enable one, both, or neither. Leave both off and every request is free and auto-approved. Stripe requires an internet connection, so it's unavailable in Local Only mode.

  • Set prices

    Per-song and 3-song bundle pricing, plus your Stripe key if enabled.

Admin controls

Once running, open the admin screen and enter your PIN for playback controls, catalog refresh, approval-mode toggle, and End Session — the same screen that lets you change kiosk mode, network mode, music source, or PIN later.

Bartender pairing

Share the bartender URL shown in admin settings with your bartender. They open it in any browser on the same network, enter their name and the bar PIN, and are ready to approve requests. The first person to pair becomes session admin; additional bartenders need admin approval.

Network setup

These are the same three options from the setup wizard above, in more detail.

Bar WiFi

Connect the Android device and all customer/bartender devices to the same router.

Common issue — AP isolation

Most venue routers have client isolation ("AP Isolation") on by default on guest networks — it blocks devices from reaching each other even though they can all reach the internet. Fix: disable "Isolate WiFi clients" in the router's guest-network settings and reboot the router afterward.

Android Hotspot

Enable the hotspot in Android Settings first (usually under Network & Internet → Hotspot & tethering). Customers and bartenders join your device's hotspot directly — no external router, no isolation issues.

Tip

The most reliable option if you don't control the venue's router settings — the device handles everything itself.

Internet / Relay

Connects to the jukebars.com relay over the internet. Customers use a shareable QR link that works on any network; bartenders can approve from anywhere with internet access. The device still plays the music locally — only requests, approvals, and now-playing state pass through the relay.

FAQ — Android & Spotify specific

For network, PIN, reports, and other questions common to both platforms, see the general FAQ on the overview page.

Spotify isn't playing / no sound

Confirm the Spotify device selected during setup is still active — reopening the setup wizard's Spotify device step and re-selecting it re-establishes the connection. Make sure the device has an active Spotify Premium subscription and an internet connection.

My local MP3 folder isn't showing tracks

Confirm the app has storage/media permission (Android will prompt for this the first time you pick a folder). Only audio files directly inside the selected folder are picked up — check you selected the right sub-folder, not a parent folder with no files directly in it.

Can I change kiosk mode or network mode after setup?

Yes — open the admin screen, enter your PIN, and choose End Session. This re-runs the setup wizard from the kiosk-mode screen, pre-filled from your last session.

Privacy — Spotify & local files

See the full privacy table on the overview page for the complete picture — this section covers the two Android-specific details.

Spotify: sign-in uses Spotify's own browser-based login (PKCE) — JukeBar never sees or stores your Spotify password. Only playback control and playlist-reading access are used; JukeBar does not access your Spotify listening history or account details beyond what's needed to play the selected playlist.

Local files: audio files are read directly from the device's storage to build the on-device catalog. Nothing about your local file library is transmitted anywhere.
